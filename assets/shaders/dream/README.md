# Dream Shaders

These shaders are optional visual layers for the dream sequence.

They must never be required for story progression.
If compilation fails, the game must fall back to black screen or a normal dream background.

## dream_fall_xskgrw.frag

Source: https://www.shadertoy.com/view/XsKGRW

Usage:
- dream_1_fall
- about 5 seconds

Purpose:
- falling
- fragmentation
- disorientation
- short unstable transition

Fallback:
- black screen + dream_1_fall text

## dream_future_mtcgdf.frag

Source: https://www.shadertoy.com/view/MtcGDf

Usage:
- dream_2_suspend
- dream_3_future_choice
- dream_3_future_far
- dream_3_future_together
- dream_3_future_create

Purpose:
- quiet floating space
- future fragments
- distance and light

Fallback:
- soft dream background or black screen
