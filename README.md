# 第一日 / 第一天

> 基于 C++ / Qt Widgets 的视觉小说式互动叙事 Demo

## 设计理念
高中生活中，几乎每个人都会经历一些濒临崩溃的时刻：考试失利、人际孤独、家庭变化，或那些无法说出口的压力。而真正改变我们的，往往不是某个宏大的转折，而是一个朋友的陪伴、一个老师的关心或者终于愿意放过自己的那一刻。《第一天》想呈现的，正是一个人如何在这些微小而真实的支撑中，被带出泥潭，走向之后的人生“第一天”。

## 项目简介
《第一天》是一个基于真实经历改编的叙事驱动互动体验 Demo，采用接近视觉小说的形式进行呈现。项目以我的 2025 年 3 月一个周五傍晚为背景，围绕一次二诊成绩公布后的情绪崩塌、人与人之间的陪伴展开。玩家将通过场景切换、文字叙述与少量关键选项，走进一段可以被重新体验的记忆。该项目希望表达的并不是“如何赢得游戏”，而是在人生低谷中，一个选择、一次倾诉、一次被接住，可能如何改变一个人的感受与成长轨迹，玩家需要试图把这段本该十分悲伤的回忆变得温暖一些，把他带到明天。我想用这个作品来表达我自己，以及我对那些人的感激。

## 项目背景

- 本项目为《高级语言程序设计》课程大作业。
- 开发语言为 C++，图形界面基于 Qt Widgets。
- 选题重点在于创意表达、完成度与图形化交互实现。

## 核心功能

- 标题页与“开始游戏”按钮
- 冷开场
- 文本推进
- 角色名与对话显示
- 场景切换
- 选项按钮与悬浮二选一交互
- 主线与支线
- 隐藏梦境彩蛋
- 背景图切换
- 音效与 BGM 播放
- 雨夜热点点击
- 状态变量记录

## 剧情与分支结构

- 冷开场：固定失败线，从 `cold_open_0_black` 开始。
- 场景 1-5：前期铺垫与轻互动。
- 场景 6：关键分支。
- 跟他下楼走两圈：进入主线。
- 想在教室里写作业：进入支线。
- 主线：`7A -> 8 -> 9 -> 10 -> 11 -> 12`
- 支线：`7B -> 10 -> 11 -> 12`
- 梦境：隐藏彩蛋，需要前面多次表现出“想休息 / 想睡”的倾向。

## 技术实现

- 开发语言：C++
- 图形化框架：Qt Widgets
- 构建方式：CMake
- 场景数据：JSON 驱动

主要模块：

- `GameWindow`：主界面、标题页、文本显示、交互响应与场景表现
- `NarrativeEngine`：场景推进、选项处理、变量写入与条件跳转
- `Scene / Interaction / GameState`：剧情数据结构与状态记录
- `StoryLoader`：读取 `data/story_main.json`
- `DialoguePanel / FloatingChoiceLayer`：对白框与中央悬浮选项 UI
- `AudioManager`：BGM、环境音、音效与 UI 音频管理

技术重点：

- 将剧情拆分为场景节点
- 使用选项驱动场景跳转
- 使用变量记录玩家选择与隐藏状态
- 使用背景、音乐、音效和 shader 演出增强叙事表现

## 运行方式

### 方式一：使用 Qt Creator 打开

1. 安装 Qt 6，并确保包含 `Widgets`、`OpenGL`、`OpenGLWidgets`、`Multimedia` 模块。
2. 使用 Qt Creator 打开根目录下的 `CMakeLists.txt`。
3. 配置 Kit 后构建并运行。

### 方式二：命令行构建

以下命令适用于已经正确配置 Qt 6 CMake 环境的情况：

```powershell
cmake -S . -B build
cmake --build build
.\build\MyFirstDay.exe
```

说明：

- 程序运行时会从相对路径读取 `data/`、`assets/` 与 `图/` 目录中的资源。
- 如果你的 Qt 未加入默认搜索路径，需要额外设置 `CMAKE_PREFIX_PATH`。

## 操作方式

- 鼠标点击继续推进文本
- 出现选项时点击对应按钮
- 部分场景可点击画面中的对象或热点
- 标题页点击“开始游戏”进入剧情
